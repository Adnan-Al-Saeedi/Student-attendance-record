# سجل حضور المرحلة الثانية

تطبيق ويب لتسجيل حضور طلبة المرحلة الثانية في قسم تقنيات شبكات وبرمجيات الحاسوب، كلية البوليتكنك / بابل، جامعة الفرات الأوسط التقنية، للفصل الدراسي الأول 2026-2027.

- تسجيل الحضور لكل مادة وشعبة على مدى 15 أسبوعاً، بتواريخ المحاضرات الفعلية من الجدول الأسبوعي.
- سجل الفصل لكل مادة، وملخص القسم، وتقارير نسب الغياب تُنزَّل ملفات Word.
- يدخل كل تدريسي برمز شخصي، ولا يقرأ ولا يكتب إلا مواده. الخادم هو من يفرض ذلك.

## كيف يعمل

- **الواجهة**: على GitHub Pages، وملفاتها `index.html` و`app.js`.
- **الخادم والبيانات**: جدول Google Sheets على حسابك، معه سكربت Google Apps Script (`apps-script/Code.gs`) يستقبل الطلبات ويحفظ الحضور في الجدول.
- **لا مفاتيح في المستودع**: رابط الخادم يُحفظ في أسرار المستودع، ويكتبه GitHub Actions في `config.js` عند النشر. أسماء الطلبة ورموز الدخول تبقى في الجدول، ولا تُرفع إلى GitHub.

ملاحظة: رابط الخادم يصل إلى متصفح من يستخدم الموقع مهما أُخفي في المستودع. لكن الرابط وحده لا يكفي لشيء، لأن كل طلب يحتاج رمز دخول صحيحاً يتحقق منه السكربت.

## خطوات الإعداد (مرة واحدة)

1. **إنشاء الجدول**: أنشئ جدولاً جديداً في Google Sheets بحسابك، باسم مثل «سجل حضور المرحلة الثانية».
2. **لصق السكربت**: من داخل الجدول افتح Extensions > Apps Script، واحذف المحتوى الافتراضي، والصق محتوى `apps-script/Code.gs`، ثم احفظ.
3. **التهيئة**: اختر الدالة `setup` من القائمة أعلى المحرر واضغط Run، ووافق على الصلاحيات. تُنشأ أوراق الجدول، ويظهر **رمز دخول المدير** في Execution log. احتفظ به.
4. **النشر كتطبيق ويب**: Deploy > New deployment > Web app، واختر:
   - Execute as: **Me**
   - Who has access: **Anyone**

   ثم انسخ رابط Web app الذي ينتهي بـ `/exec`.
5. **سر المستودع**: في GitHub افتح Settings > Secrets and variables > Actions > New repository secret، وأضف `APPS_SCRIPT_URL` وقيمته الرابط الذي نسخته.
6. **تفعيل Pages**: Settings > Pages > Source: **GitHub Actions**، ثم من تبويب Actions شغّل «نشر التطبيق على GitHub Pages».

## بعد النشر

1. افتح الموقع وادخل برمز المدير.
2. في تبويب **الإدارة** استورد قائمة الطلبة من ملف Excel بأعمدة: التسلسل، اسم الطالب، الشعبة (A أو B).
3. أنشئ رمز دخول لكل تدريسي، وسلّمه إياه شخصياً. رئيس القسم يطّلع على جميع المواد ويسجّل مادته فقط. لإيقاف دخول تدريسي اضغط «إلغاء الرمز»، ثم أنشئ له رمزاً جديداً إذا لزم.

## عند تعديل السكربت

بعد أي تعديل على `Code.gs` انشره من جديد عبر Deploy > Manage deployments > Edit > Version: New version، ليبقى الرابط نفسه.

لتغيير رمز المدير شغّل الدالة `resetAdminCode` من المحرر، واقرأ الرمز الجديد في السجل.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة والتنسيق |
| `app.js` | منطق التطبيق والتقارير والاتصال بالخادم |
| `apps-script/Code.gs` | الخادم: التحقق من الرموز، والصلاحيات، والحفظ في الجدول |
| `config.example.js` | نموذج لملف الإعداد للتجربة المحلية |
| `.github/workflows/deploy.yml` | إنشاء `config.js` من الأسرار ونشر الموقع |
